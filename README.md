# 扫雷 (DSH GameCenter 示例游戏)

DSH 游戏中心首个官方示例小游戏：经典扫雷 (Minesweeper)。

## 特性

- **确定性规则引擎**：翻格、插旗标记、相邻雷数计算、空白扩散（Flood Fill）、胜负判定全部由本地确定性规则引擎负责。
- **首击保护**：首次点击位置绝对安全，杜绝开局踩雷。
- **AI 仅生成对局**：通过 slot `boardGeneration` 请求结构化雷位对局数据；局内裁决与改雷由本地引擎严密封闭。
- **严格校验与安全保底**：对 AI 模型输出进行格式、棋盘尺寸、雷数、越界、重复雷位与首击安全性校验；校验未通过或离线时自动切换确定性本地 Fixture，保障 100% 可玩。
- **状态序列化与关闭恢复**：完整支持每动作检查点（`save.checkpoint`）、虚拟时钟（暂停与离线不累计现实时间）与生命周期管理（`lifecycle.register`）。
- **零依赖自包含产物**：`dist/` 目录下产物开箱即用，无需外部构建或网络请求。

## 运行与测试

```bash
# 运行单元测试 (A7 / A8 验证)
npm test

# 打包自包含产物
npm run build
```
